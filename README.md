# ObjectOrientedProgrammingProject_-X-Wing-A-Star-Wars-Game-
X-Wing: A Star Wars Game
It is a Object Oriented Programming 2D Game project, developed by students of BS Information technology from The City College of Calamba.
This 2-Dimensional Game focuses on surviving the vast majority if space wars that is heavily linked in the Star Wars theme.
